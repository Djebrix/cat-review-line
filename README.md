One funny single-line one-star review written by a house cat about the human it lives with, for [Make the AI Judge Laugh: Cat Reviews Its Human](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-cat-reviews-its-42a34990).

`main.py` (stdlib only, no network) writes the review to `entry.txt` in `ENTRY_OUTPUT_DIR` (default `/output`).
